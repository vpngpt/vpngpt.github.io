三、详细教程：两种方式导入Vmess链接

方法一：手动输入配置（适合学习理解）

虽然粘贴链接更便捷，但了解手动配置有助于你深入理解各参数的意义：

  1. 打开小火箭，点击底部"配置"标签
  2. 选择右上角"+"号，点击"添加配置"
  3. 在类型中选择"Vmess"
  4. 依次填写：
    • 地址：服务器域名或IP地址
    • 端口：通常是443或其它指定端口
    • 用户ID：由服务商提供的UUID字符串
    • 额外ID：多数情况下填0
    • 加密方式：一般为"auto"或"none"
    • 传输协议：可选择tcp、ws、kcp等
  5. 完成后点击"保存"，配置将出现在列表中

方法二：剪贴板导入（推荐日常使用）

这是最常用的方式，只需几秒钟：

  1. 从你的服务商处复制完整的Vmess链接（通常以"vmess://"开头）
  2. 打开小火箭应用，停留主界面
  3. 应用会自动检测剪贴板中的代理链接并弹出提示
  4. 点击"导入"，系统会自动解析所有参数
  5. 确认信息无误后点击"保存"

专业提示：如果链接未能自动识别，可进入"配置"页面，点击右上角"+"，选择"从剪贴板导入"。

FAQ

如何配置 Sing-box 使用 DoH 加密 DNS？
在 dns 模块中添加类型为 doh 的上游，如 `https://1.1.1.1/dns-query`，并指定 bootstrap 地址。启用加密 DNS 可防止 DNS 泄露并加快国际解析速度，提高整体隐私保护。
Matsuri 的节点自动测速功能如何配置？
Matsuri 可以设置测速周期和节点列表，程序会自动测试延迟和速度并排序。用户可根据测试结果选择最佳节点，提高网络访问速度和使用体验。
Netch 使用 TAP 驱动时 Windows 弹出网络变更提示，该如何处理？
这是正常现象，TAP 虚拟网卡会改变系统网络状态。建议在首次启用时允许驱动安装并授予网络权限，若频繁弹窗可在网络设置中调整网络识别类型或将 TAP 设为非计量连接。
Hiddify Next 如何为不同用户设置流量限制？
管理员可为每个用户设置独立带宽限制和流量配额。超过限制时，可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提升整体网络效率和公平性。
V2Ray 如何设置多入口实现不同访问控制？
通过定义多个 inbound，对不同端口绑定不同的 tag 并在路由中匹配流量。可针对内网用户、远程用户或特定 IP 段应用不同规则，实现灵活访问控制与流量隔离。
Netch 的全局代理与规则代理有何不同？
全局代理将所有流量都通过节点转发，而规则代理只针对指定 IP、端口或应用。全局代理适合游戏和全局科学上网，规则代理适合优化带宽和分流特定流量。
Trojan-Go 是否支持 WebSocket？
Trojan-Go 增强了原版 Trojan，支持 WebSocket、gRPC 等多种传输方式。通过这些传输层协议，可在伪装网站下运行代理服务，提高隐蔽性和灵活性。
Matsuri 如何提升节点连接效率？
Matsuri 是一个支持多协议的代理工具，强调快速连接与自动切换功能。它可以根据延迟自动选择最优节点，减少手动切换的繁琐过程，保证网络体验的流畅性。
VLESS + XTLS 在移动网络下的优势有哪些？
XTLS 模式减少握手次数和加密开销，适合高延迟或不稳定的移动网络。结合策略组和多节点切换，可提升网页浏览、视频播放和游戏的连接稳定性和流畅度。
V2Ray 的 outbound freedom 模式有什么作用？
freedom 是直连模块，可用于分流策略中实现部分流量直连。用户可在 routing 中设置匹配规则，将国内域名或局域网 IP 指向 freedom 出口，从而减少代理开销和延迟。
