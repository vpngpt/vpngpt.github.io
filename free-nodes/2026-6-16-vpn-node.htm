安装指南：从零开始轻松配置

第一步：选择合适的浏览器

谷歌科学上网扩展主要支持基于Chromium内核的浏览器，包括：
- Google Chrome
- Microsoft Edge

- Opera

如果您尚未安装上述浏览器，建议优先下载Google Chrome，以确保最佳兼容性。

第二步：访问Chrome应用商店

  1. 打开浏览器，在地址栏输入：chrome.google.com/webstore。
  2. 在搜索框中输入关键词，如“科学上网”“代理扩展”或具体扩展名称（如“XX VPN”）。
    注意：部分扩展可能因地区限制无法直接搜索到，可尝试通过开发者官网或第三方渠道获取CRX文件手动安装。

第三步：安装扩展

  1. 找到目标扩展后，点击“添加到Chrome”按钮。

  3. 安装完成后，浏览器右上角将出现扩展图标。

第四步：基础配置

  1. 服务器设置：点击扩展图标，输入代理服务器地址（通常由服务商提供）。
  2. 协议选择：根据网络环境选择HTTP、SOCKS5等协议（推荐SOCKS5以兼顾速度和安全性）。
  3. 连接测试：使用扩展内置的测试功能，确认代理是否生效。

2. 多节点切换

遇到速度缓慢时：

- 部分扩展支持“智能路由”，可自动选择最优线路。

3. 安全加固

  • 定期更新扩展：修复漏洞，避免被防火墙检测。
  • 启用双重加密（如Chacha20-IETF-Poly1305协议）。

FAQ

Mellow 使用透明代理时如何避免 DNS 泄露？
在 Mellow 中启用 fake-ip 或内置 DNS 解析功能，并将上游 DNS 指定为 DoH/DoT 服务，确保所有 DNS 请求通过代理转发而非本地解析，从而避免 ISP 或本地网络捕获实际访问域名。
Mihomo 节点分组如何自动切换最佳节点？
将节点按延迟、地区或用途分组，并启用策略组功能，系统会根据节点延迟和健康状态自动切换到最佳节点，保证网页、视频和游戏连接稳定流畅。
VMess 使用 AEAD 加密后连接性能如何？
AEAD 加密在保证数据安全的同时，性能开销较低，抗重放攻击能力强。高封锁环境下更稳定，同时减少流量特征泄露，适合长时间和高安全性需求的网络连接。
Mellow 是否支持自定义 DNS？
支持。Mellow 的配置文件中可设置 DNS 服务器地址及模式（如 DoH、DoT）。用户可使用安全 DNS，如 Cloudflare 1.1.1.1 或 Google DNS，以减少污染风险。
PassWall2 支持哪些内核？
PassWall2 支持多种代理内核，如 Xray、V2Ray、Sing-box、Trojan-go、Hysteria2 等。用户可在插件管理中切换所需内核，以获得不同协议与性能的支持。部分内核需手动下载并启用。
Clash 是否支持 DNS 分流？
支持。Clash 可以自定义 DNS 服务器，并通过 rules 区分国内外域名解析方式。比如国内网站可使用本地 DNS，国外网站可走代理 DNS，从而提升访问速度与稳定性。
WinXray 节点延迟检测如何优化视频访问？
WinXray 定期测速节点延迟和丢包率，并结合策略组自动选择最佳节点。保证视频流量通过低延迟节点，减少缓冲和卡顿，提高播放流畅度和网络体验。
Hysteria2 多路复用在短连接中优势是什么？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适合高频短连接场景，如游戏和即时通讯，提升吞吐量和连接稳定性，优化网络体验。
Clash 的 Profile URL 是否可以同时添加多个？
可以。Clash 支持导入多个 Profile URL，用户可在“配置”面板切换不同订阅源。多个配置之间互不干扰，方便区分不同地区或用途的线路。
如何防止租用服务器被用作滥发或代理滥用？
限制对外端口与协议，使用防火墙与入侵检测（如 fail2ban），监控流量异常并设置告警，定期审计登录行为，及时阻断滥用源并与服务商沟通封禁滥用账户以防引起供应商封禁整台机。
